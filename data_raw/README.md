# Raw data

1. Open a family's [OpenFWI](https://openfwi-lanl.github.io/) Google Drive folder below.
2. Click the folder name at the top, then **Download**. Large folders arrive as several zips.
3. Extract every zip here. You get one folder per family, such as `data_raw/FlatVel_A/`.
